## Purpose

This file is the active execution roadmap for the Universal RCC
Chimneys website.

Tasks should be completed in dependency order unless a task is
explicitly independent.

Codex should:

1. Check this file before beginning substantial work.
2. Work on the highest-priority unblocked task.
3. Keep task status accurate.
4. Validate completed work.
5. Add newly discovered tasks when necessary.
6. Avoid starting downstream implementation before its dependencies are
   sufficiently complete.

# Task Management Rules

When a task is completed:

1. Change `[ ]` to `[x]`.
2. Record important validation where useful.
3. Add newly discovered follow-up tasks.
4. Update related documentation if necessary.

When blocked:

1. Change status to `[!]`.
2. Explain the blocker.
3. Identify what is required to unblock it.

When a task is no longer required:

Change its status to `[~]` and document the reason.

Do not silently delete project history.
